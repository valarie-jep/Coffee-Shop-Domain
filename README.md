# Coffee Shop OOP Project

This is a Python object-oriented project that models the basic domain of a coffee shop. It includes the following classes:

- `Customer`: Represents a customer of the coffee shop.
- `Coffee`: Represents a type of coffee.
- `Order`: Represents an order placed by a customer for a specific coffee.

All classes are written in pure Python and tested using `pytest`.
